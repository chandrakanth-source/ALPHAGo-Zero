1.We need some kind of look-ahead search.That's where MCTS comes in.Instead of selecting high probabiltiy moves.
2.Imagine you're playing chess and thinking: "If I make this move, what will the opponent do?"
  then : If they do that, what should I do?" You're mentally creating a tree.
3.Why can't we search the entire Go tree? : Because Go has an enormous number of possible games.Even on a 9×9 board, the number of possible game sequences is huge.
4.Instead we want Explore the most promising parts of the tree.That's the basic idea behind MCTS.
5.The four steps of MCTS :(SEEB)
   Step 1 — Selection :Start at the root.We need to decide which branch to explore.
                    MCTS doesn't simply pick a random branch.It balances:
                      Exploitation  : "This move has performed well before."
                      Exploration   :  "We haven't investigated this move much yet.
            This is called the:     exploration vs exploitation problem
        AlphaGo Zero uses a PUCT-style selection rule:  a∗=argamax​[Q(s,a)+U(s,a)]
                 where : Q :How good has action a been based on previous searches?
                         U :is the exploration term
                           =U(s,a)=cpuct​P(s,a)*(ROOT(N(s))/1+N(s,a))
                           P(s,a) :The neural network's prior probability for move a
                           N(s)   :Number of times the parent state has been visited.
                           N(s,a) :Number of times we have selected action a.
                           c_puct :Controls how strongly we encourage exploration.
            NOTE : The neural network does not simply say:Play the highest-probability move."
            INSTEAD :Neural Network gives rior probabilities and thenMCTS uses them to guide search  and then MCTS investigates positions and then Final move selection.
   Step 2 — Expansion  :Eventually MCTS reaches a node that hasn't been explored.We expand that node by generating its legal moves.
                       Now those moves are available to explore.
   Step 3 — Evaluation  :n traditional MCTS, you might perform a random simulation/rollout until the game ends.
                        But AlphaGo Zero does something different.It uses the neural network.
                        The network receives the new board: adn then it is gien to the neural network and policy ,value are genertated.
​​                         AlphaGo Zero does not need random rollouts to the end of every game. 
   Step 4 — Backup     : We propagate that information back through the path we followed.The result is backed up:This updates the search tree.
6.After complettion of these four steps ,qe have completed the four steps which means we have completed the one simulation.
7.But one simulation isn't enough.We repeat this many times.After many simulations :MCTS now has much more information.
8.So instead of:Neural network says B = 40%.we have:MCTS says B was explored most successfully and the agent selects B according to the final search policy.
9.What information does every MCTS edge/node maintain?
         N   : How many times has this action/state been visited?
         W   : What is the accumulated evaluation?
         Q   : Average value.Q=W/N
         P   : Prior probability.

3.Without the Ko rule, the players could repeat forever.So Go prevents certain immediate repetitions.
4.For our project, we will use a simple positional Ko rule:A move is illegal if it produces a board position that has already occurred in the game., and it is known broadly as the Superko rule.
5.Basic Ko    :A player cannot immediately recapture a single stone if it recreates the exact previous local position. You must play a "ko threat" elsewhere first.
6.Positional Superko  :A move is illegal if it recreates any full-board position that has occurred at any point earlier in the game.
7.Situational Superko  :A move is illegal only if it recreates a previous full-board position and it is the same player's turn to move.
